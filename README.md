# 週刊誌風サムネイルジェネレーター

**AIで、ネタを週刊誌風に。**

URLやテキストを入力するだけで、AIが自動で週刊誌の中吊り広告風のサムネイル画像を生成するツールです。

- **Firecrawl API** でWebページから情報を取得
- **Gemini API** で情報を週刊誌風のYAMLプランに変換
- **Gemini API** でYAMLプランから画像を生成

![サンプル画像](https://i.imgur.com/example.png)  <!-- 後で実際のサンプル画像に差し替える -->

## 主な機能

- **URL/テキスト/ファイルから生成**: Web記事、テキスト、ドキュメントファイルからサムネイルを生成できます。
- **AIによるYAMLプラン生成**: ネタをAIが自動で週刊誌風の見出しやレイアウトに変換します。
- **AIによる画像生成**: YAMLプランを元に、AIがサムネイル画像を生成します。
- **修正ガチャ機能**: 生成されたYAMLプランをAIが自動で調整し、様々なバリエーションを試せます。
  - **カラー**: 青系、緑系、黄色系など6種類
  - **フォント**: 超極太、モダン、手書きの3種類
  - **テキスト**: 短く、ドラマチック、フォーマルの3種類
  - **レイアウト**: コンパクト、シンプルの2種類
  - **ランダム**: 予想外の組み合わせを生成
- **比較ビュー**: 複数の生成結果を並べて比較できます。
- **静的サイトとしてデプロイ可能**: APIキーはブラウザのlocalStorageに保存され、サーバーには送信されません。

## 技術スタック

- **フロントエンド**: Vite, HTML, CSS, JavaScript
- **AI**: Google Gemini API (gemini-3-pro-preview, gemini-3-pro-image-preview)
- **Webスクレイピング**: Firecrawl API
- **CSSフレームワーク**: TailwindCSS v4 (dev)
- **YAMLパーサー**: js-yaml

## セットアップ方法

1. **リポジトリをクローン**
   ```bash
   git clone https://github.com/Trudibussi/Magazine_Thumbnail_Generator.git
   cd Magazine_Thumbnail_Generator
   ```

2. **依存関係をインストール**
   ```bash
   npm install
   ```

3. **開発サーバーを起動**
   ```bash
   npm run dev
   ```
   ブラウザで `http://localhost:5173` を開きます。

4. **プロダクションビルド**
   ```bash
   npm run build
   ```
   `dist/` ディレクトリに静的ファイルが生成されます。

## 使い方

1. **APIキーを設定**
   - アプリケーション上部の「API設定」セクションに、お持ちの **Gemini APIキー** と **Firecrawl APIキー** を入力します。
   - キーはブラウザのlocalStorageに保存され、外部には送信されません。

2. **ネタを入力**
   - **URL**: Web記事のURLを入力します。
   - **テキスト**: テキストを直接貼り付けます。
   - **ファイル**: テキストファイルやドキュメントをドラッグ＆ドロップします。

3. **生成設定**
   - **アスペクト比**: `16:9` や `1:1` などを選択します。
   - **生成枚数**: 1枚から10枚まで選択します。

4. **サムネイルを生成**
   - 「サムネイルを生成」ボタンをクリックします。
   - AIがYAMLプランを生成し、続けて画像を生成します。

5. **結果を確認・調整**
   - 生成された画像がギャラリーに表示されます。
   - 下のYAMLエディタでプランを直接編集できます。
   - 「修正ガチャ」ボタンでAIに自動調整させることも可能です。
   - 調整後、「再生成」ボタンで新しい画像を生成します。
